## Background

Hack the North is Canada's biggest student-run hackathon, where 1,000+ students from around the world build something in 36 hours. A year before joining, I'd applied as a hacker and gotten rejected, so getting to help build it as a frontend organizer felt like a full-circle moment!

## Building it

Every year has a new theme, so the website and the hacker application get redesigned from scratch. On hackthenorth.com, I built the hacker testimonials and sponsors sections, and on the application, I worked on the long answer questions.

I was also the DRI for the travel tool, my first time leading a project. Backend changed buses to support multiple stops, like UMichigan → Western → UWaterloo sharing one capacity, so I updated how the frontend finds buses and assigns hackers to stops.

## Looking back

We also started building a volunteer tool in-house to replace a pricey third-party one. It didn't make it out in time, but it set things up nicely for next year's team.
